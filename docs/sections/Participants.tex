In this section, I will be talking about the meaning of participants. The primitive participants have attributes that are established, for example, type. However, as part of the design's meaning, participants can have custom attributes. 

For example, the meaning of a book includes its name and contents. So in the narratives, if I say that the book is assigned a name, then there is a specific attribute of the participant that is being updated. So as part of the narratives I can also specify this.

\begin{greyquote}
    A book has a name and it has contents. The name is a string and content is a string. The books name and contents are both accessible and assignable.
\end{greyquote}

I can create ways in which this participant can be interacted with, so when I say, I get the books name, this has unambiguous meaning.
